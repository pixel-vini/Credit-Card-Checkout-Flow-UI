# 💳 Credit Card Checkout Flow

A modern and user-friendly **Credit Card Checkout Flow** designed for a seamless mobile payment experience. Built in Figma with a clean, component-driven design system.

<br />

> 🔗 **[View Figma Prototype →](https://www.figma.com/design/0RlvI1IZncpctn8qcseka1/Credit-Card-Checkout?node-id=0-1&t=A6WhH50n5tXBU19p-1)**

<br />

---

## 📱 Screen Overview

The flow consists of **4 screens**, each guiding the user through a step of the checkout process:

### 1. 🛒 Order Summary
Displays a clear breakdown of items in the cart — product names, quantities, prices, and the total amount before the user proceeds.

### 2. 📦 Shipping Information
A clean form screen where users enter their delivery details — full name, email address, street address, city, and ZIP/postal code — with a minimal, distraction-free layout.

### 3. 💳 Credit / Debit Card Payment
A visually rich payment screen featuring a live card preview that updates as users fill in their details. Fields include card number, cardholder name, expiry date, and CVV — designed with security and clarity in mind.

### 4. ✅ Payment Confirmation
A success state screen that confirms the transaction with an order reference number, a summary of the purchase, and estimated delivery information — giving the user confidence their order went through.

## ✨ Design Highlights

- **Mobile-first** — optimized for standard smartphone screen sizes
- **Component-driven** — every UI element is built as a reusable Figma component
- **Consistent spacing** — Auto Layout ensures pixel-perfect padding and alignment
- **Accessible layout** — clear visual hierarchy with readable typography and contrast
- **Interactive prototype** — fully clickable flow from cart to confirmation
